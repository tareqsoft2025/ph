# PhotoSync Telegram

تطبيق Android (Kotlin + Jetpack Compose، واجهة عربية RTL) لإرسال صور الاستديو إلى بوت Telegram يدويًا، أو تلقائيًا للصور الجديدة بعد تفعيل المستخدم للميزة صراحةً.

> **ملاحظة صدق:** كُتب المشروع في بيئة بلا Android SDK (مستودعات Google محجوبة)، لذلك **لم يُبنَ ولم تُشغَّل اختباراته هنا**. افتحه في Android Studio وابنِه؛ إن ظهر خطأ تجميع فهو على الأرجح بسيط (import أو إصدار مكتبة).

## بنية المشروع

```

├─ MainActivity.kt                  التنقل (Bottom bar) + فرض RTL
├─ data/
│  ├─ Models.kt                     PhotoItem / Bucket / SendStatus
│  ├─ Database.kt                   Room: جدول send_log (سجل + منع التكرار)
│  ├─ SettingsRepository.kt         الإعدادات؛ التوكن في EncryptedSharedPreferences
│  ├─ MediaRepository.kt            قراءة MediaStore حسب الإذن + وصف صور المنتقي
│  └─ SendLogRepository.kt          السجل ومسحه
├─ telegram/
│  ├─ TelegramApi.kt                OkHttp: getMe/getChat/getUpdates/sendMessage/sendPhoto/sendDocument
│  ├─ PhotoUploader.kt              إرسال صورة واحدة: سياسة الحجم، إعادة المحاولة، تحديث السجل
│  └─ SendCoordinator.kt            طابور الإرسال اليدوي + التقدم + الإيقاف
├─ work/

│  ├─ AutoSendWorker.kt             فحص الصور الجديدة وإرسالها
```

الشاشات: الرئيسية · المعرض · السجل · الأتمتة · الإعدادات والخصوصية · إعداد Telegram.

## إنشاء البوت والحصول على Bot Token و Chat ID

1. في Telegram افتح **@BotFather** ← `/newbot` ← اختر اسمًا ومعرّفًا ينتهي بـ `bot` ← سيعطيك **Bot Token** (`123456789:AA...`). لا تشاركه مع أحد.
2. **Chat ID**:
   - *محادثة خاصة:* افتح بوتك وأرسل `/start`.
   - *مجموعة:* أضف البوت وأرسل رسالة فيها (قد يلزم تعطيل Privacy Mode من BotFather أو جعله مشرفًا).
   - *قناة:* أضف البوت **مشرفًا** بصلاحية النشر، وأدخل `@اسم_القناة` أو الرقم الذي يبدأ بـ `-100`.
3. في التطبيق: **إعداد Telegram** ← الصق التوكن ← **اكتشاف Chat ID** (يعرض المحادثات التي راسلت البوت) ← **اختبار الاتصال** ← **إرسال رسالة اختبار**.

## التشغيل على هاتف حقيقي وبناء APK

1. ثبّت Android Studio (Koala أو أحدث) وJDK 17، وافتح مجلد المشروع ودع Gradle يزامن.
2. على الهاتف: الإعدادات ← حول الهاتف ← اضغط «رقم الإصدار» 7 مرات ← خيارات المطور ← فعّل **تصحيح USB**، ثم وصّله واقبل البصمة.
3. اضغط **Run ▶** (الجهاز ظاهر في الأعلى).
4. لملف APK: `./gradlew assembleDebug` ← الناتج `app/build/outputs/apk/debug/app-debug.apk`، انسخه للهاتف وثبّته (اسمح بالتثبيت من مصدر غير معروف). للتوزيع استخدم Build ← Generate Signed Bundle/APK.
5. الاختبارات: `./gradlew testDebugUnitTest` (اختبارات TelegramApi بـ MockWebServer وسياسة الحجم وإعادة المحاولة).

## الصلاحيات

| الصلاحية | سببها |
|---|---|
| `INTERNET` | الاتصال بـ Telegram |
| `READ_MEDIA_IMAGES` (13+) / `READ_EXTERNAL_STORAGE` (≤12) | عرض صور المعرض والأتمتة |
| `READ_MEDIA_VISUAL_USER_SELECTED` (14+) | يدعم منح وصول جزئي لصور محددة |
| `POST_NOTIFICATIONS` (13+) | إشعار الأتمتة (اختياري) |

يمكنك دائمًا استخدام **منتقي الصور الرسمي** (زر المجلد في المعرض) بلا أي إذن. لا يطلب التطبيق صلاحية الفيديو أو الملفات.

## الإرسال في الخلفية: قيود صريحة

- الإرسال التلقائي عبر `WorkManager`: أقل فترة **15 دقيقة**، والتوقيت تقريبي وليس فوريًا ولا مضمونًا.
- قد يؤجله أو يمنعه Doze، توفير البطارية، «تقييد الخلفية»، أو الإيقاف القسري للتطبيق (خصوصًا على بعض أجهزة Xiaomi/Huawei/Oppo).
- الإرسال **اليدوي** يعمل ما دامت عملية التطبيق حية؛ إن قتلها النظام تبقى الصور «قيد الانتظار/فاشلة» في السجل وتُعاد من هناك.
- الأتمتة تُرسل فقط الصور المضافة **بعد** التفعيل (نقطة بداية)، والصور الفاشلة تُعاد محاولتها حتى 5 مرات.

## افتراضات وقرارات تقنية

- `minSdk 26`، `targetSdk 34`؛ الواجهة عربية دائمًا (RTL مفروض).
- **التوكن لا يُضمَّن في الكود/APK**؛ يُدخله المستخدم ويُحفظ مشفّرًا (Android Keystore). لا يُسجَّل في أي Log، ورسائل الأخطاء تُنقّى منه. التطبيق مصمم ليستخدم كل مستخدم بوته الخاص؛ إن أردت توزيعه بتوكن مركزي فاستخدم خادمًا وسيطًا يحمل التوكن ويقبل الصور بمصادقة.
- منع التكرار: مفتاح فريد لكل صورة (`ms:<MediaStore id>` أو اسم+حجم لصور المنتقي). الإرسال اليدوي يتخطى المرسَل سابقًا افتراضيًا، وإعادة إرساله تتطلب قرار المستخدم.
- الصورة >10MB أو التي ترفض Telegram أبعادها تُرسل تلقائيًا كملف (`sendDocument`)؛ الحد الأقصى 50MB.
- مسح السجل أثناء تفعيل الأتمتة يعيد نقطة البداية إلى «الآن» كي لا تُرسل الصور القديمة مجددًا.
- `allowBackup=false` وحركة الشبكة HTTPS فقط.
