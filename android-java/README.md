# PhotoSync Telegram — نسخة Java (APK جاهز)

تطبيق Android أصلي بلغة **Java** بدون Gradle ولا مكتبات خارجية، يُبنى بأدوات `aapt`/`dx`/`apksigner`.

**الملف الجاهز:** `dist/photosync-telegram.apk` (Android 10 فأحدث). هذه النسخة العامة **لا تحتوي أي بوت
أو توكن**؛ تحتاج إدخال بيانات Telegram يدويًا مرة واحدة. لنسخة شخصية تأتي مهيّأة ببوتك مسبقًا، ابنِها محليًا
(قسم «ثوابت Telegram» أدناه) ولا ترفعها إلى أي مكان عام.

## التثبيت
1. انقل الملف إلى الهاتف وافتحه (اسمح بالتثبيت من مصدر غير معروف لهذا التطبيق).
2. الإعدادات داخل التطبيق: **الرئيسية ← إعداد Telegram** ← الصق Bot Token و Chat ID ← «اختبار الاتصال».
   - Token: من @BotFather (`/newbot`). Chat ID: افتح بوتك وأرسل `/start` ثم «اكتشاف Chat ID».

## الميزات
- معرض الصور (ألبومات، تحديد متعدد، معاينة، تاريخ وحجم) + منتقي الصور الرسمي بلا أذونات.
- إرسال `sendPhoto`/`sendDocument` مع تقدم وإيقاف وإعادة محاولة ومعالجة حد الإرسال ومنع التكرار.
- أتمتة (JobScheduler): صور جديدة فقط، Wi-Fi فقط، فترة الفحص، إشعار دائم بزر إيقاف.
- سجل SQLite مع إعادة المحاولة والمسح. التوكن مشفّر بـ Android Keystore ولا يُسجَّل.
- **فحص التحديثات:** عند كل فتح للتطبيق، وبزر يدوي في الإعدادات، يتحقق من `update.json` في هذا المستودع؛
  عند وجود إصدار أحدث يظهر إشعار يفتح رابط تنزيله (لا تثبيت تلقائي). لأن كل الإصدارات تُوقَّع بنفس المفتاح
  (`debug-keystore.jks`، مفتاح تجريبي غير حساس ومُتتبَّع عمدًا في git)، يُثبَّت التحديث فوق النسخة القديمة
  مباشرة دون الحاجة لإلغاء التثبيت أولًا.

## ثوابت Telegram (نسخة شخصية مهيّأة مسبقًا)
التطبيق يدعم إعداد بوت/محادثة افتراضيين مُضمَّنين في الكود، بحيث يعمل من أول تشغيل بلا إدخال يدوي
(وتبقى شاشة الإعدادات قادرة على تغييرهما أو حذفهما في أي وقت). هذه القيم توضع في ملف **محلي لا يُرفع إلى git**:

```bash
cp src/com/photosync/telegram/Secrets.java.example src/com/photosync/telegram/Secrets.java
# عدّل DEFAULT_BOT_TOKEN وDEFAULT_CHAT_ID داخل الملف بقيمك الفعلية
./build.sh   # يرفض البناء إن لم يوجد Secrets.java، ليُذكّرك بإنشائه أولًا
```

`Secrets.java` مُدرَج في `.gitignore` عمدًا: لا تُزل هذا الاستثناء ولا تُجبر إضافته (`git add -f`)، فالمستودع
عام وأي توكن يُدفع إليه مرة واحدة يبقى في تاريخ git إلى الأبد حتى بعد حذفه أو إلغائه.

## البناء من المصدر
```bash
sudo apt install aapt apksigner zipalign dalvik-exchange default-jdk-headless
./build.sh        # ينزّل android-all.jar ويُخرج build/photosync-telegram.apk (VERSION_CODE/VERSION_NAME قابلان للتجاوز كمتغيرَي بيئة)
./test.sh         # اختبارات JVM لطبقة Telegram (junit4 + libandroid-json-org-java)
```

### نشر تحديث للأجهزة المثبَّت عليها التطبيق
عند أي تعديل تريد وصوله كتحديث:
1. ارفع `VERSION_CODE`/`VERSION_NAME` في `build.sh` (أو مرّرهما كمتغيرَي بيئة).
2. ابنِ الـAPK وادفعه إلى `dist/photosync-telegram.apk`.
3. حدّث `update.json` بنفس الرقمين ورابط الملف، وادفعه معه في نفس الـcommit.
   الأجهزة المثبَّت عليها التطبيق تكتشف الفرق تلقائيًا (فحص صامت عند فتح التطبيق) وتعرض إشعار التحديث.

## قيود
- الإرسال التلقائي تقريبي (≥15 دقيقة) وغير مضمون مع Doze/توفير البطارية.
- الإرسال اليدوي يعمل ما دامت عملية التطبيق حية.
- فحص التحديثات يحتاج اتصالًا بالإنترنت ويعتمد على بقاء `update.json` محدَّثًا يدويًا مع كل إصدار؛ ليس آليًا بالكامل (لا متجر تطبيقات هنا).
- لم يُشغَّل على جهاز/محاكي حقيقي في بيئة التطوير؛ المتحقق منه: البناء والتوقيع وفحص البيان واختبارات Telegram.
