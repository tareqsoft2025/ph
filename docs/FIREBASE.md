# تفعيل الإشعارات الفورية (Firebase)

الإشعارات الفورية تصل إلى تطبيق الأندرويد **حتى لو كان مغلقاً تماماً**: "الطلب جاهز" للنادل، و"طلب جديد" للمطبخ، وطلبات الإجازة، ونقص المخزون.

بدون هذا الإعداد يعمل النظام طبيعياً، لكن الإشعارات تصل فقط والتطبيق أو الصفحة مفتوحة، ولو كانت في الخلفية.

يحتاج الإعداد ملفين من مشروع Firebase مجاني على حسابك:

| الملف | مكانه | سري؟ |
|---|---|---|
| `google-services.json` | داخل تطبيق الأندرويد: `web/android/app/google-services.json` | لا، يمكن رفعه للمستودع |
| ملف حساب الخدمة (`...-firebase-adminsdk-....json`) | على جهاز الخادم فقط | **نعم، لا ترفعه للمستودع أبداً** |

---

## 1) إنشاء مشروع Firebase

1. افتح https://console.firebase.google.com وسجّل الدخول بحساب Google.
2. اضغط **Create a project / إنشاء مشروع**، وسمّه مثلاً `restaurant`. يمكنك إيقاف Google Analytics.

## 2) إضافة تطبيق الأندرويد (للحصول على `google-services.json`)

1. من صفحة المشروع اضغط أيقونة **Android**.
2. في **Android package name** اكتب بالضبط: `com.ph.restaurant`
3. اضغط **Register app**، ثم **Download google-services.json**.
4. ضع الملف في المستودع في المسار `web/android/app/google-services.json`. يمكنك رفعه من صفحة GitHub عبر **Add file → Upload files** داخل مجلد `web/android/app`، أو أرسله لي وأبني التطبيق به.

## 3) مفتاح الخادم (حساب الخدمة)

1. في Firebase اضغط ⚙️ **Project settings**، ثم تبويب **Service accounts**.
2. اضغط **Generate new private key**، ثم **Generate key**، فيُنزَّل ملف JSON.
3. ضع الملف على **جهاز الخادم** (الكمبيوتر الذي يشغّل `npm start`) بإحدى طريقتين:
   - انسخه إلى `backend/firebase-service-account.json`، وهذا الاسم مستثنى من Git تلقائياً.
   - أو حدّد مساره بمتغير بيئة:
     ```bash
     FIREBASE_SERVICE_ACCOUNT=/path/to/key.json npm start
     ```
4. أعد تشغيل الخادم. يجب أن تظهر الرسالة:
   ```
   🔔 الإشعارات الفورية مفعّلة (Firebase: restaurant-xxxxx)
   ```

> **API المطلوب:** يستخدم الخادم Firebase Cloud Messaging API (V1)، وهو مفعّل افتراضياً في المشاريع الجديدة. إن لم يكن مفعّلاً، فعّله من **Project settings ← Cloud Messaging**.

## 4) بناء التطبيق مع Firebase

بعد وضع `google-services.json` في `web/android/app/`:

```bash
cd web && npm run apk
```

أو من GitHub Actions: أضف سراً باسم `GOOGLE_SERVICES_JSON` يحتوي نص الملف كاملاً، من **Settings ← Secrets and variables ← Actions**. سيُبنى التطبيق به تلقائياً.

## 5) التجربة

1. ثبّت التطبيق الجديد وسجّل الدخول، ثم اسمح بالإشعارات عند السؤال.
2. افتح **الإعدادات ← الإشعارات**، فيجب أن تظهر "مفعّلة على هذا الجهاز".
3. اضغط **إرسال إشعار تجريبي**، ثم أغلق التطبيق تماماً وأرسل طلباً من جهاز آخر وجهّزه في المطبخ. سيصل إشعار "الطلب جاهز" للنادل.

---

### كيف يعمل
- عند فتح التطبيق يسجّل الجهاز رمزه لدى الخادم (`POST /api/push/register`) مرتبطاً بالمستخدم.
- عند كل إشعار يرسل الخادم رسالة إلى أجهزة المستخدمين المستهدفين عبر FCM HTTP v1. يوقّعها بمفتاح حساب الخدمة، دون مكتبات إضافية.
- الضغط على الإشعار يفتح الصفحة المرتبطة به، مثل الطلب الجاهز.
- الرموز التي لم تعد صالحة تُحذف تلقائياً، وعند تسجيل الخروج يُلغى تسجيل الجهاز.
- قناتا إشعارات على الأندرويد: **الطلبات** (أولوية عالية مع صوت واهتزاز) و**عام**.
- إذا لم يحتوِ التطبيق على `google-services.json` يبقى يعمل طبيعياً بالإشعارات المحلية، ولا يحاول تسجيل Firebase.
